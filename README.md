# KnowledgeEngineeringRetailStore

## Aim
To create a Knowledge Repository for a real-world business system and make it publicly accessible on a cloud-based platform such as GitHub.

## Theory:
In this experiment, a Retail Store Management System is used as the business system. The repository contains information about products, customers, orders, and business rules. GitHub is used as a cloud-based platform to store and make the repository publicly accessible.

## Result:
A structured Knowledge Repository for a Retail Store Management System was successfully created using Python and made publicly accessible through GitHub.
